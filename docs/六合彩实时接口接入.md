# 六合彩在线接口接入（2026-09-22）

本文件记录实际接入，覆盖《京东六合彩页面接口需求》中此前拟定的路径参数、鉴权、快照和预测结构约定。

- 彩种固定 `mark-six-demo`，群聊 `customInfo.gameid` 作为原始 `machineCode` 查询参数。机器码不放入路径、不作为 `groupUid` 传递。
- 基址统一读取 `GROUP_QUERY_BASE_URL`，默认留空：调试和正式构建均回退到 App 主服务，由主服务转发，不再默认直连 `47.242.90.129`。六合彩 HTTP、WebSocket 与查/反/历共用此切换项；三公保持不变。构建时若曾显式设置该参数为测试 IP，需移除该参数或设为空后重新启动应用。
- 独立无鉴权 Dio 客户端，不发送 JWT、Cookie、X-Group-Id、InstanceId。
- 初始化并行 GET `/api/v1/lotteries/mark-six-demo/config`、`draws?limit=100`、`predictions?window=40&limit=100`，三个请求均带 machineCode。
- 初始化完成连接同路径 `/ws?machineCode=...&window=40&limit=100`。HTTPS 自动对应 WSS。
- 处理 config/draws/predictions 推送；heartbeat 仅用于连接存活与服务端时钟校准，不清空开奖结果。
- 断线每15秒重新 HTTP 初始化并重连；45秒无消息也触发重连。后台或无页面使用时停止网络，恢复前台重新同步。
- 切换统计窗口后重新请求预测并重连对应窗口；用请求代次屏蔽已关闭、旧窗口的迟到结果。
- 预览、全屏共享会话，缓存按服务端、账号、会话、机器码隔离。相同机器码共用对应机器人实例的数据；服务端回显的 groupUid 可不同于 IM 群 UID，初始化校验三次回显一致，推送校验已解析群。
- 号码映射来自 config；历史属性保留服务端返回值，不用当前规则重新解释历史。旧 admin/robot-desk/number-mappings 不再用于开奖页面加载。
- 所有时间按毫秒解析，按 config.timezone（IANA）显示；时钟使用 serverTime 加单调计时器。
- 开奖历史仅显示 drawn，open/closed 作为等待状态，不当成一次开奖计入统计。完整 issue 用于刮开状态，issueLabel 用于显示。
- 预测使用 data.items，actual 为属性对象；不自行算命中，不编造下一期。样本不足、未发布、待开奖、取消分别显示。
- 遗漏/冷热改为共用后端 statistics：进入统计标签时请求 overview 获取快照，再请求指定 attribute 的 statistics；409 SNAPSHOT_EXPIRED 刷新概览后最多重试一次。WS statistics 一次替换九项属性，优先于此前发出的 HTTP 请求。范围切换清除旧统计；零样本保留全部候选并显示“暂无样本”。次数、占比、冷热标签、遗漏下限均直接读取后端。
- 长龙仍基于已加载真实开奖记录计算，最多40期；遇 sequence 缺口不计算。尚未调用 streaks。
- 2026-09-22 联调：公网 WS 已收到 statistics；机器 BDEP-T685-JSWQ 的 overview 刚返回的快照用于 HTTP statistics 仍出现 SNAPSHOT_EXPIRED，需后端核对快照生成/校验一致性。说明中的 GZKH-DJ3M-VKSB 在当前公网返回 MACHINE_NOT_FOUND。
- 无数据、失败不回退演示开奖结果；已有缓存遇到连接错误显示提示。401/403/404 清空当前会话的数据。

实现：`lib/src/api/lottery_live_api.dart`；UI：`lib/src/pages/settings/lottery_dashboard.dart`。

设置中的测试入口已移除。未传机器码的内部演示构造仍保留给现有组件测试，不是群聊联网入口。
