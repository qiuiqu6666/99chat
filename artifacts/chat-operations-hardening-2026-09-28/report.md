## 已完成的修复

| 链路 | 修复与恢复行为 |
| --- | --- |
| 正式版日志 | 应用会关闭 `debugPrint`，因此聊天诊断改用 VM 日志并接入独立的文件缓冲。记录操作编号、运行编号、UTC 时间、会话/消息编号、阶段与错误类型；不传入聊天正文或完整 SDK 对象。对凭据、正文类字段和 URL 做过滤，限制字段和单行长度。 |
| 本地留存 | 应用私有目录 `chat_recovery/recent.log` 与 `previous.log` 各最多 256 KiB；内存待写队列最多 200 条，每批最多 20 条。文件写入串行；失败延迟重试，悬挂时队列仍有上限。不会让日志异常抛回聊天调用方。 |
| 排查入口 | 设置 → 聊天问题排查，支持保存文本文件、复制记录。附应用版本、平台、保存失败数、丢弃数、当前会话及已保存事件。没有自动上传。磁盘或平台插件不可用时，导出退回当前内存记录；文件准备过程有超时。 |
| 首屏反馈 | 3 秒未显示时出现“正在加载消息…”；12 秒仍未恢复提供“重新加载”。保持上一轮已有的 25 秒重试释放和已有内容揭示机制。 |
| 返回最新消息 | 整个最新窗口加载最多等待 20 秒，超时作废本次窗口权限、恢复可重试状态。SDK/数据库迟到结果不能继续以旧请求发布窗口。取消信号异常也会结束本次请求。 |
| 可见性确认 | 原来 `confirming` 可能永远指向一个不返回的数据库任务，后续点击一直复用它。现在确认最多等待 12 秒，结束时清除属于自己的状态；过期回调不能继续确认当前视口。窗口清理同时解除旧确认引用。 |
| 持久消息窗口 | 最新窗口准备、窗口重置和未读确认增加调用有效性校验；排队期间已经过期的操作不再执行窗口替换或未读确认。仍保持原有账号、会话、访问代次和水位线约束。 |
| 监听生命周期 | 退出/账号切换及写入租约失效时，先隔离并移除 SDK 监听，再等待心跳、消息队列和租约收尾。生命周期等待超过 25 秒时记录队列、处理阶段和在途时长，失败和最终恢复也有记录。 |

## 数据一致性边界

超时只结束 UI 等待，不代表原生 SQLite/SDK 已经取消。正在执行的持久写入仍保留顺序；不会为了显示“恢复成功”而放行相互覆盖的写入、提前清除未读或重复发送撤回命令。

数据库恢复返回后，过期操作受到权限检查，后续请求可以继续。数据库永远不返回、设备存储损坏或 SDK 原生线程永久失效，不能仅靠 Dart 定时器保证修复。本轮确保相关 UI 等待有期限，并留下可定位阶段的记录；没有把这类底层故障宣称为已经全部消除。

## 客服与开发排查方法

异常发生后记录大致时间、单聊/群聊、当时的操作；在设置中保存排查记录。严重情况重启后，也可以导出此前已写入的记录。文件为有限滚动留存，尚未完成的最后一批写入可能在强杀时丢失。

| 事件 | 定位含义 |
| --- | --- |
| `revoke_clicked` → `revoke_sdk_call` → `revoke_sdk_result` | 菜单进入、调用 SDK、SDK 回应。结合 operation 与 message 判断是否真正发起撤回。 |
| `revoke_local_published` / `revoke_message_list_updated` / `revoke_ui_frame` | 本地乐观发布、列表更新、对应帧完成；这些事件不单独证明 SDK 撤回成功。 |
| `revoke_prepare_failed` / `revoke_sdk_late_result` / `mutation_completion_retry` | 分别定位本地准备、SDK 迟到回应、本地完成写入重试。 |
| `history_failed` / `history_released` | 分页失败阶段、请求代次与加载状态是否释放。 |
| `latest_reload_timeout` | 返回最新的窗口准备/加载没有在期限内结束。 |
| `latest_proof_timeout` | 消息可见性确认未结束，未读保留供后续重试。 |
| `return_clicked` / `return_failed` / `return_finished` | 返回底部操作的入口、失败与最终位置结果。 |
| `viewport_transition_expired` | 过渡层未正常结束，期限到达后释放触摸遮挡。 |
| `realtime_lifecycle_waiting` / `realtime_teardown_wait` | 区分生命周期排队、心跳、消息队列、租约释放等等待。 |
| `realtime_lifecycle_failed` / `realtime_lifecycle_resumed` | 生命周期任务异常或结束；resumed 只表示等待结束，是否成功需结合失败事件。 |
