# 顶部自定义分组切换闪空修复

范围：用户确认的会话列表顶部自定义分组。修改 conversation.dart、conversation_feed_body.dart，新增 conversation_folder_loading_test.dart；保留工作区其他改动，未提交。

## 原因与修改

- 分组成员不在已加载会话窗口中时，需要按 100 条分批向 SDK 补查；原界面仅按当前行数判断空状态。现在使用现有请求代次标记加载状态，在全部批次结束前不显示“空会话”；已有行可以立即展示。
- 快速切换 A→B→A 时，只有当前分组、当前账号、当前请求代次可以结束加载。旧响应不能关闭新请求的加载提示。
- 点击已经选中的分组不再清空列表或重复请求；失败后允许重试，但尚有批次进行时不重复发起。重试保留已加载行，只补查缺失成员。
- SDK 失败与真正空分组分别展示，失败可手动重试，不无限自动请求。
- 分组成员变化但名称不变时也刷新成员投影，并使旧请求失效。
- 可见列表筛选先建立规范化成员 Set，替代每条会话扫描全部分组成员，减少大列表筛选成本；保持既有来源顺序、会话类型及身份归一化规则。
