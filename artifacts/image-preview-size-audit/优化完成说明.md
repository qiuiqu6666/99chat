# 全屏图片预览自适应优化完成记录

本次修改产品代码，未提交或推送。保留其他本地调试产物。

## 行为

- 普通照片保持比例完整入画；能够以源像素尺寸放入视口的小图使用 scaleDown，不再初始放大到全屏。
- 聊天长图默认阅读宽度为 min(视口宽度, 视口高度, 720)，并且不超过原始宽度的 2 倍。手机竖屏通常仍贴宽，横屏保持较稳定的阅读列，桌面/平板居中显示。
- 长图原始尺寸由调用方传给渲染组件，解码分辨率升级不再改变阅读宽度；窗口变化按图像坐标保留阅读中心，在顶部时保持顶部。Hero 盒与显示分类随窗口变化刷新。
- 超大图改用二维区域网格与 InteractiveViewer 的真实变换，支持长图、横向全景和大照片的缩放、横向/纵向移动及双击。
- 网格按可见区域取块，使用分级采样，单块目标不超过 512×512。每个预览实例同时最多 2 个在途请求，旧请求也占用名额直到结束。过期/离屏结果丢弃，重复块请求合并。
- 手机缓存最多 48 块、桌面 96 块，输出位图预算分别最多约 48/96 MiB；这是区域输出预算，不是进程峰值或原生解码器全部内存承诺。
- 保留图集边缘横滑翻页和顶部下拉关闭；分块解码失败仍可缩放、滑动查看缩略图，且保留同一阅读宽度策略。
- 移除旧 image_preview_tile_geometry.dart，区域请求测试迁移到新网格。
